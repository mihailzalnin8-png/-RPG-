> **Текстовая RPG** — это классическая консольная RPG с магазином, крафтом, аренами, боссами и хардкором.
> А ещё — настоящий **LAN-мультиплеер**: хост запускает игру, остальные сканируют QR и играют в браузере.
> Командой против волн или друг против друга. С чатом, передачей ресурсов и админ-панелью.

- 🎭 **9 классов** со своими способностями, маной и перезарядкой.

## 🚀 Быстрый старт

### 1. Проверь Python

Нужен **Python 3.10+**. Проверка:

```bash
python --version
```

> ✅ Проверено на Windows 11 и Python 3.14.5.

Если команда не найдена, попробуй `py --version` или установи Python с [python.org](https://www.python.org/downloads/).
При установке на Windows отметь **Add Python to PATH**.

### 2. Возьми три файла

Положи их в одну папку:

```text
1rpg_fixed (2).py
multiplayer.py
phone_server.py
```

Установщик и BAT-файлы не нужны: игра запускается прямо из папки.
Например, можно создать папку `C:\Users\user\Saved Games\TextRPG` и держать всё там.

### 3. Запусти игру

```bash
python "1rpg_fixed (2).py"
```

> 💡 Запускай игру **из её папки**, чтобы сейвы `save.json` и `global_progress.json` создавались рядом с игрой.

### 4. (Необязательно) QR в консоли

```bash
python -m pip install qrcode
```

Без модуля `qrcode` игра и мультиплеер работают, но QR-код не нарисуется — останется ссылка для ручного ввода.
С ним QR показывается прямо в консоли и на странице `/qr`.

## 📱 Мультиплеер за 30 секунд

```text
Телефон 1 ─┐
Телефон 2 ─┼── Wi-Fi ── ПК с Python ── браузер хоста
Телефон 3 ─┘
```

1. Запусти игру и выбери **`7. 🌐 Мультиплеер`**.
2. Выбери режим: **`1. 🤝 Команда`** или **`2. ⚔️ PvP`**.
3. На компьютере откроется страница хоста, в консоли появится адрес и QR.
4. Остальные игроки сканируют QR или вводят адрес вида `http://192.168.1.10:8030/`.
5. Каждый выбирает имя и класс, затем жмёт **«Я готов»**.
6. Когда готовы все — игра стартует автоматически. Хост может начать принудительно.

> ⏹️ Остановка сервера: введи **`stop`** и нажми Enter в консоли.
> Игроки получат уведомление примерно за 3 секунды. Пустой Enter ничего не делает.
> Команда **`status`** покажет порт, число игроков и код комнаты.

### 🔌 Что нужно для подключения

- Телефон и компьютер в **одной Wi-Fi сети**.
- Разреши Python доступ к **частной сети** в брандмауэре Windows.
- Отключи VPN и «изоляцию клиентов» на роутере, если телефон не видит компьютер.

## 🎮 Как проходит бой

1. В свой ход выбери действие: **атака**, **способность**, **зелье**, **защита** или **пропуск**.
2. Для атаки и большинства способностей сначала выбери цель.
3. Когда сходили все живые игроки, сервер разрешает раунд: срабатывают защита, лечение, способности и урон.
4. Передумал? Меняй ход, пока не сходили остальные.
5. Между волнами можно передавать союзникам золото и ресурсы.
6. В PvP цель — остаться последним выжившим. В команде — пройти все волны вместе.

## ⚙️ Настройки комнаты

Меняет только хост и только в лобби.

| Настройка | Значения | По умолчанию |
|---|---|---|
| Сложность | Лёгкая / Обычная / Сложная | Обычная |
| Волн | 2–4 | 4 |
| Таймер хода | 10–300 секунд | 30 |
| Стартовое золото | 0–5000 | 50 |
| Пароль комнаты | до 24 символов | без пароля |

**Защита пароля:** 5 неверных попыток с одного адреса — блокировка на 60 секунд.
Уже вошедших игроков пароль не затрагивает.

## 🛠️ Админ-панель и QoL

Хост видит панель прямо в браузере:

- 👢 **Кик** — удалить игрока из комнаты.
- ⛔ **Бан** — запретить повторный вход.
- 🔇 **Мут чата** — запретить писать.
- 🐢 **Медленный чат** — не чаще одного сообщения в N секунд.
- ♻️ **Разбан** — вернуть игрока в игру.
- 🔄 **Рестарт** — вернуть всех в лобби с сохранением настроек.

Что доступно всем игрокам:

- ✅ **Готовность** и автостарт, когда готовы все.
- ✏️ **Смена хода**, пока не сходили все: можно передумать.
- 🪪 **Смена своего ника** тапом по имени.
- 💬 **Чат** с сохранением черновика.
- 🔇 **Локальный мут** конкретного игрока — только у тебя.
- 👤 **Профиль**: игры, победы, винрейт, любимый класс.
- 🔑 **Код возврата** и карточка последней комнаты.
- 📋 **Копирование ссылки** и кода комнаты.

## 💾 Данные и сохранения

### Файлы игры

| Файл | Что хранит |
|---|---|
| `save.json` | Обычное сохранение одиночной игры |
| `hardcore_save.json` | Хардкорное сохранение |
| `global_progress.json` | Глобальный прогресс: квесты, гильдия, разблокировки, дата рождения |

> Мультиплеер **не трогает** одиночные сейвы: у героев мультиплеера отдельные статы,
> а состояние комнаты живёт в памяти сервера.

### Данные в браузере

Мультиплеер хранит настройки телефона в `localStorage` (привязаны к адресу и порту):

| Ключ | Назначение |
|---|---|
| `mp_token` | Текущая сессия игрока |
| `mp_client` | Постоянный ID устройства |
| `mp_name`, `mp_class` | Последние имя и класс |
| `mp_profile_v1` | Статистика профиля |
| `mp_last_room_v1` | Карточка последней комнаты |
| `mp_muted_<код>` | Локально скрытые игроки |

> Состояние сервера не сохраняется на диск: после перезапуска создаётся новая комната
> с новым кодом. Для возврата внутри одной сессии используй код возврата.

## 📂 Структура проекта

```text
TextRPG/
├── 1rpg_fixed (2).py   # Игра: одиночный режим, меню, сохранения
├── multiplayer.py      # LAN/QR-мультиплеер: сервер + браузерный клиент
├── phone_server.py     # Мобильный терминал для одиночной игры
└── README.md           # Этот файл
```

| Файл | Роль |
|---|---|
| `1rpg_fixed (2).py` | Вся одиночная игра. В главном меню пункт `7` запускает мультиплеер, в меню героя пункт `25` — телефонный режим. |
| `multiplayer.py` | HTTP-сервер на стандартной библиотеке, JSON API и одностраничный клиент. Порты `8030–8059`. |
| `phone_server.py` | Отдаёт мобильную страницу-терминал с выводом игры и полем ввода. Порты `8000–8029`. |

## 🧩 Технические детали

- 🐍 **Только Python и стандартная библиотека**; `qrcode` — необязательный бонус.
- 🌐 Встроенный `ThreadingHTTPServer`, без Flask и внешних зависимостей.
- 🔄 Клиент опрашивает снапшот состояния примерно раз в 600 мс.
- 🧾 Обмен данными — JSON, версия состояния увеличивается при каждом изменении.
- 🎲 Броски, урон и способности считает сервер: клиент не может подкрутить цифры.
- 🔒 Пароль комнаты, баны и лимит попыток проверяются на сервере.

Основные адреса:

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/` | Браузерный клиент |
| `GET` | `/qr` | Большой QR-код для подключения |
| `GET` | `/qr.svg` | SVG QR-кода |
| `GET` | `/api/state?token=…` | Снапшот комнаты |
| `POST` | `/api/join` | Вход или возврат по коду |
| `POST` | `/api/ready` | Готовность |
| `POST` | `/api/action` | Ход в бою |
| `POST` | `/api/chat` | Сообщение в чат |
| `POST` | `/api/transfer` | Передача золота или ресурсов |
| `POST` | `/api/settings` | Настройки комнаты |
| `POST` | `/api/admin` | Кик, бан, мут, замедление |
| `POST` | `/api/restart` | Рестарт в лобби |

## 🩺 Если что-то не работает

| Проблема | Причина | Решение |
|---|---|---|
| Телефон не открывает ссылку | Разные сети или VPN | Подключи оба устройства к одной Wi-Fi сети, выключи VPN |
| Ссылка не открывается, порт занят | Другой процесс на `8030–8059` | Закрой старый сервер или перезапусти игру: порт выберется автоматически |
| Нет QR в консоли | Не установлен `qrcode` | `python -m pip install qrcode` |
| «Сессия не найдена» | Сервер перезапускался | Вернись по коду возврата или через карточку последней комнаты |
| Забыли пароль | Пароль задан хостом | Хост открывает настройки в лобби и сбрасывает пароль |
| «Слишком много попыток пароля» | Сработала защита от перебора | Подожди 60 секунд и попробуй снова |
| Телефон отключается в фоне | Браузер экономит батарею | Держи вкладку активной или вернись по коду |

## ⚠️ Ограничения

- 📶 Мультиплеер работает **в локальной сети**. Не выставляй его в интернет: это HTTP без шифрования.
- 🎮 Одна комната на один запущенный сервер.
- 👥 От 2 до 4 игроков.
- 🦷 Bluetooth пока не поддерживается: браузер не умеет открывать RFCOMM напрямую.
- 💾 Состояние комнаты живёт до остановки сервера. Профиль, мут и последняя комната сохраняются в браузере.
